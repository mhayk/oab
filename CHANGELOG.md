# Changelog

All notable changes to this project are documented here.

The format is based on [Keep a Changelog](https://keepachangelog.com/en/1.1.0/), and this project
adheres to [Semantic Versioning](https://semver.org/spec/v2.0.0.html).

Because OAB's behaviour is its interface, a change to a framework procedure that materially changes
the architecture OAB recommends is treated as a **breaking change**, the same as a schema change.

## [Unreleased]

### Added

- Founding design proposal covering vision, repository architecture, the Claude Code integration,
  knowledge representation, seven reasoning frameworks, the evaluation strategy, milestones, risks,
  and a sequenced M1 execution plan (`docs/design/`).
- Brand assets: canonical mark and icon as true SVG drawn from isometric geometry, and the wordmark
  lockup generated from Sora outlines by `tools/build_wordmark.py`.
- Repository foundation: Apache-2.0 licence, `NOTICE` with trademark terms, contributing guide,
  code of conduct, security policy, roadmap.
